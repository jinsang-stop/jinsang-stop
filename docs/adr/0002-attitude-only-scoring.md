# 채점은 태도 3축만 하고, 직무 조치의 옳고 그름은 판정하지 않는다

상태: accepted

훈련 세션의 점수는 정서 안정 · 공감 인정 · 경계 설정 세 축으로만 매긴다. 사용자가 규정을 정확히 안내했는지,
해주면 안 되는 것을 약속했는지, 상급자에게 넘겼어야 할 건을 혼자 처리했는지는 채점하지 않는다. 리포트에도
"올바른 조치" 항목을 두지 않는다.

직무 조치를 채점하려면 직업군마다 정답지를 사람이 따로 써야 하고, 그 정답지는 업종·사업장·지자체마다 달라
유지 비용이 무한히 늘어난다. 우리는 **"이 상황에서 규정상 맞는 대응이 무엇인지 알려주는 기능을 포기하는 대신"**,
직업군을 늘릴 때 3축 루브릭과 채점 프롬프트를 그대로 재사용하는 확장 비용의 저렴함을 얻는다. 알바에서 검증한
채점기가 공무원·교사 카드에도 수정 없이 붙는다.

이 결정은 제품 문구에도 제약을 만든다 — "올바른 응대법을 배운다"고 말할 수 없고, "흔들리지 않는 태도를
훈련한다"고 말해야 한다. 시나리오 카드에 적는 '양보하면 안 되는 선'도 정답 판정용이 아니라 민원인 연기의
재료로만 쓴다. 직무 정오 판정을 넣자는 요구가 다시 나오면 이 문서를 먼저 읽는다.
