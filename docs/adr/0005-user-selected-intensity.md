# 민원인의 공격 강도는 사용자가 고르는 3단계로 상한을 둔다

상태: accepted

시나리오 카드를 시작할 때 사용자가 강도 1~3단계를 고르고 기본값은 1단계다. 단계마다 민원인에게 허용되는
행동을 프롬프트에 명시적으로 열거하며, 열거되지 않은 행동은 하지 않는다. 강도를 올려도 넘지 않는 절대선
(성적 발언, 신체적 위협 묘사, 특정 집단에 대한 혐오 표현 등)은 단계와 무관하게 전역으로 금지한다. 세션 중
언제든 즉시 중단할 수 있어야 하고, 강도 2단계 이상은 시작 전에 무엇이 나올 수 있는지 고지한다.

강도를 아예 낮게 고정하면 배포는 안전하지만 "실전에서는 안 통하더라"는 제품이 되고, 현장 수준을 그대로
재현하면 몰입감은 최대지만 이용자 심리 피해 위험과 약관·심사 부담을 그대로 떠안는다. 우리는 **모든 사용자에게
동일한 훈련 경험을 제공하는 단순함을 포기하는 대신**, 사용자가 자기가 감당할 수 있는 만큼만 노출되도록 통제권을
넘기고, 표류 가능한 "알아서 심하게 굴어라" 식 프롬프트를 쓰지 않아도 되는 검증 가능성을 얻는다.

이 결정은 강도가 시나리오 카드 스키마의 일부이고, 단계별 프롬프트와 단계별 검수 기준을 각각 만들어야 한다는
뜻이다. 성장 기록도 강도를 섞어 비교할 수 없으므로 같은 강도끼리만 이어 그린다. 절대선 목록은 코드가 아니라
문서로 관리하고, 모델 안전 필터에 걸려 응답이 끊기는 경우의 처리도 여기에 따라붙는다.
