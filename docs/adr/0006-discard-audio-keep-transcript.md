# 음성 원본은 채점 직후 폐기하고, 전사와 점수만 보관한다

상태: accepted

훈련 세션 기록은 로그인한 계정에 귀속되어 서버에 저장하되, 저장 대상은 텍스트 전사와 축별 점수, 소요 턴 수,
종료 사유까지다. 사용자 음성 파일은 전사와 채점이 끝나는 즉시 폐기하며 보관하지 않는다. 민원인 TTS 음성도
재생 후 보관하지 않는다.

음성을 남기면 사용자가 자기 억양과 말끝을 다시 들어보며 점검할 수 있어 훈련 효과가 분명히 커진다. 그러나
음성은 전사 텍스트와 개인정보로서의 무게가 달라 보관 기간·별도 동의·삭제 요청 처리·유출 시 파급을 모두
따로 설계해야 하고, 스토리지 비용도 계속 붙는다. 우리는 **"내 목소리 다시 듣기" 기능을 포기하는 대신**,
개인정보 처리 범위를 텍스트로 좁혀 MVP의 동의 절차와 운영 부담을 최소화한다.

이 결정은 리포트와 성장 기록이 전사 텍스트만으로 성립해야 한다는 제약을 만든다. 즉 채점 루브릭은 어조·성량·
말속도 같은 음성 특징을 점수에 쓸 수 없고, 전사된 말의 내용과 표현만으로 정서 안정을 판정해야 한다. 음성
특징을 채점에 넣자는 요구가 나오면 이 문서를 먼저 뒤집어야 한다.
