# 사용자 카드는 검수된 조각의 조합으로만 만들고, 자유 서술은 받지 않는다

상태: accepted

사용자는 자기만의 시나리오 카드를 만들 수 있지만, 상황·민원인 성격·요구·양보 불가선을 미리 정의된
카드 조각 보기에서 고르기만 한다. 사용자가 입력한 문장은 카드 이름을 제외하고 민원인 프롬프트에 들어가지
않는다. 이렇게 만든 카드는 내 카드이며 본인에게만 보이고, 운영이 작성·검수해 모두에게 제공하는 공식 카드와
구분된다. 성장 기록은 두 종류를 섞지 않고 카드 단위로 따로 이어 그린다.

자유 서술을 허용하면 사용자가 자기 현장을 그대로 재현할 수 있어 훨씬 강력하지만, 그 텍스트가 그대로 민원인
페르소나가 되므로 [[ADR-0003]]의 사전 검수와 [[ADR-0005]]의 강도 상한이 동시에 우회된다. 검사기를 세워도
우회 시도와의 싸움이 계속 남는다. 우리는 **사용자가 자기 상황을 문장으로 묘사하는 표현력을 포기하는 대신**,
프롬프트에 들어가는 모든 문장이 우리가 쓴 문장이라는 구조적 안전성과, 별도 검사기·모더레이션 운영이
필요 없다는 단순함을 얻는다.

이 결정은 카드 조각 보기의 품질이 곧 사용자 카드의 표현 범위라는 뜻이다. 조각이 빈약하면 "내 상황이 없다"는
불만이 바로 나오므로, 조각 목록을 넓히는 것이 공식 카드를 늘리는 것과 별개의 지속적인 운영 업무가 된다.
자유 서술 요구가 다시 올라오면 검사기 설계와 함께 새 ADR로 다룬다.
