# Triage Labels

스킬들은 다섯 개의 표준 트리아지 역할로 말한다. 이 파일이 그 역할을 이 저장소 이슈 트래커의 실제 라벨 문자열에 매핑한다.

| 표준 역할          | 이 트래커의 라벨   | 의미                                |
| ----------------- | ----------------- | ---------------------------------- |
| `needs-triage`    | `needs-triage`    | 관리자가 평가해야 하는 이슈            |
| `needs-info`      | `needs-info`      | 제보자의 추가 정보를 기다리는 중       |
| `ready-for-agent` | `ready-for-agent` | 명세가 완결되어 에이전트가 착수 가능    |
| `ready-for-human` | `ready-for-human` | 사람이 직접 구현해야 함               |
| `wontfix`         | `wontfix`         | 작업하지 않음                        |

스킬이 역할을 언급하면(예: "에이전트 착수 가능 라벨을 붙여라") 이 표의 오른쪽 문자열을 쓴다.

실제로 쓰는 어휘가 다르면 오른쪽 칸만 고친다.

## 이 저장소의 상태

아직 생성하지 않음. GitHub 저장소를 만든 뒤 `gh label create`로 다섯 개를 만든다.
